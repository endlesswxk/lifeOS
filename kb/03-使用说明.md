# 使用说明

这份文件写给**拿到这个文件夹的人**：不管是你自己三个月后再翻，还是你转给朋友。
读完这一份，就知道包里有什么、怎么用、遇到问题怎么办。

> 30 秒版本：**要打勾就打印 PDF；要查就双击 `site/index.html`；要算证据就看卡片里的出处。**

---

## 一、你会拿到三样东西

| | 是什么 | 适合什么时候用 | 需要装东西吗 |
|---|---|---|---|
| **一页纸清单**<br>`一页纸清单/个人健康检查清单.pdf` | A4 单页、58 条、每条带「不做的后果」 | 贴在冰箱上、打印出来打勾 | 不用 |
| **网页版知识库**<br>`site/index.html` | 单文件、66 张卡、能搜能筛、离线可用 | 想知道某件事到底怎么回事 | 不用，双击即开 |
| **可检索知识库 + 脚本**<br>`知识库/`、`数据与脚本/` | Markdown 卡片、JSON 数据、Python 脚本 | 要批量检索、要改内容、要导入 AI 记忆 | 需要 Python 3.9+ |

三个入口共用同一份内容：`数据与脚本/cards.json`。**改一处，全部重生成。**

## 二、日常怎么用（三种场景）

### 场景 A：今天就想改两条

1. 打印 `一页纸清单/个人健康检查清单.pdf`（A4，实测 1 页，不用调边距）
2. 从头到尾打一遍勾，**别挑着看**——清单是按「一票否决 → 每天 → 每周 → 每年 → 出事那一刻 → 一次性办完」排的
3. 从没打勾的里挑 2–3 条，只挑 2–3 条，写进手机提醒
4. 一个月后再打一遍

不想用纸：用 `一页纸清单/个人健康检查清单.html`，勾选状态存在浏览器本地，刷新不丢，右上角有「打印」和「清空」。

### 场景 B：突然有个具体疑问

双击 `site/index.html`（手机也能打开），然后在搜索框里用**你平时说话的词**：

```
打呼噜          胸口疼          睡不着          拉肚子
烫伤            疫苗            血压            减肥
```

- 空格 = **都要命中**：`胸口疼 出汗` 只会给出同时提到这两个的卡
- 点层级按钮可以只看某一组，比如只看 `L4 出事那一刻`（建议先把这 8 条背下来）
- 「证据」下拉可以只看 A 级，或只看没有直接证据的（D）
- 点卡片上的「怎么做、证据、误区」展开全文
- 按 `/` 键直接把光标放进搜索框

### 场景 C：把这些知识搬进 AI 记忆

见 `导入-Hindsight/IMPORT-to-hindsight.md`。**注意：那一步需要在别的机器上执行，本包没有替你写入任何记忆服务。**

## 三、命令行检索（可选）

装了 Python 就行，不需要装任何库：

```powershell
python 数据与脚本/search.py 打鼾                 # 检索
python 数据与脚本/search.py 烫伤 起火 -n 5        # 多词=或
python 数据与脚本/search.py --tag L4 --list      # 列出全部急救条目
python 数据与脚本/search.py 睡不着 --full         # 打印整张卡
python 数据与脚本/search.py --list               # 全部 66 条标题
```

## 四、证据等级怎么读（这一节别跳）

| 标记 | 含义 | 你该怎么用 |
|---|---|---|
| **A** | 随机对照试验或多队列强证据 | 可以照着做；但仍要看「不适用」一栏 |
| **B** | 大型队列 / 系统综述，**观察性**关联 | 方向可信，别把数字当成因果 |
| **C** | 弱关联，或原始口径需要修正 | 当提示，不当结论 |
| **D** | 没有直接的人群证据 | 别为它花钱 |
| **-** | 常识性安全措施或实操建议，没做分级 | 照着做，它本来就不需要论文 |

三个容易踩的坑：

1. **A 不等于推荐。** 比如「一般人群补维生素 D」是 A 级证据，但结论是**没有获益**（HR 0.99）。A 说的是证据质量，不是"该做"。
2. **数字不能相乘。** 吸烟 HR 1.54 和久坐 RR 1.04 不能乘出"风险 1.6 倍"，它们来自不同人群、不同口径。
3. **不能换算成寿命。** "少活几年"这类换算本包一律不做，原始研究也没这么算。

## 五、常见问题

**Q：我没装 Python，能用吗？**
能。`site/index.html` 是单文件网页，双击就在浏览器里跑，全部逻辑都在页面里，不联网。只有命令行检索和改内容需要 Python。

**Q：Windows 终端里中文显示成乱码怎么办？**
先设编码再运行：

```powershell
$env:PYTHONIOENCODING='utf-8'   # PowerShell
chcp 65001                       # cmd
```

**Q：手机上怎么用？**
把 `site/index.html` 发给自己（微信/邮件都行），用浏览器打开；或者按 `04-自部署说明.md` 部署到网上，用链接访问。iOS/Android 都可以。

**Q：勾选的数据会同步到别的设备吗？**
不会。清单页面的勾选存在**当前浏览器**里，网页版检索站不留任何数据、也不发任何请求。PC 和手机是两套独立状态。

**Q：能改内容吗？**
能，而且鼓励。`数据与脚本/cards.json` 是唯一来源：

```powershell
python 数据与脚本/build_kb.py     # 重建 知识库/ + 导入载荷
python 数据与脚本/build_site.py   # 重建 site/index.html
python 数据与脚本/build_refs.py   # 重建 02-引用与来源.md
python 数据与脚本/自检.py          # 16 项一致性校验
```

改 `checklist.json` 则是改一页纸清单，用 `render.py` 重建 md/html，PDF 用浏览器打印。

**Q：为什么有的卡没有具体数字？**
两种情况：一是原始研究只给了方向没给效应量（本包不自己算）；二是这条本来属于常识性安全措施（比如"不催吐""走楼梯"），没有可引用的效应量，标 `-`。

**Q：我能把它当医生用吗？**
不能。`L4 出事那一刻` 是现场处置——认信号、打 120、做按压；**不是诊断**。所有需要判断"我这是什么病"的问题，都超出本包范围。

**Q：内容错了怎么办？**
每张卡都能倒查到论文或政策原件，见 `02-引用与来源.md`（含 DOI）。发现引用错，改 `cards.json` 里那张卡的 `source` 和 `evidence`，重跑脚本，`自检.py` 会告诉你哪里不一致。

**Q：它多久更新一次？**
看包内 `README.md` 的「建成日期」和页脚的版本号。原始仓库会更新，想同步就按 `02-引用与来源.md` 最后一节的命令重取原文，再重跑脚本。

## 六、谁适合用，谁不适合

| 适合 | 不适合 |
|---|---|
| 想用最少动作拿到最大健康收益的人 | 想找症状自查、自我诊断的人 |
| 愿意看"依据是什么"而不是"专家说"的人 | 需要个体化用药/剂量方案的人 |
| 体检报告一堆箭头不知道怎么读起的人 | 已经确诊疾病、需要临床路径的人（找主诊医生） |
| 想把这些知识塞进 AI 助手长期使用的人 | 想要一个自动打卡、自动追踪的 App（那是另一件事） |

## 五、和 lifeOS（生活系统）怎么联动

知识库和 app 是两套界面：app 用来打勾和记录，知识库用来查依据。两者靠**卡片 id**连起来。

| 从哪 | 怎么过去 | 到哪 |
|---|---|---|
| app 底部导航「知识库」 | 点一下 | `kb/site/` 检索站首页 |
| app 清单里任一条的「依据 ↗」 | 点一下 | `kb/site/#c-<卡片 id>`，自动展开并高亮那张卡 |
| 知识库页面左上「← 生活系统」 | 点一下 | 回到 app（仅在 `/kb/site/` 路径下出现） |
| 知识库卡片内的「关联」 | 点一下 | 同一页内跳到相关的另一张卡 |

规则：

- **清单是唯一来源**：app 里那 58 条由 `checklist.json` 生成，改完跑
  `python 数据与脚本/build_app.py`（`deploy.py` 会自动跑）。手改 app 里的 `CHECK_SECTIONS`
  会在自检第 16 项红掉。
- **链接不会烂**：每条清单带一个 `card` 字段指向卡片 id，自检会验证 58 个 id 都真实存在；
  卡片改名或删除会立刻红。
- 深链格式就是 `#c-<卡片 id>`，和卡片内部「关联」用的锚点一致，所以链接可以随手抄给朋友。
