# 个人健康知识库

版本 1.4 · 构建于 2026-11-09 · 共 66 张卡片

## 这个库是什么

从 4 份 GitHub 知识仓库（HowToLiveLonger / HumanSystemOptimization / HowToLiveBetter / HowToCook）提炼出的健康知识卡。每张卡回答三件事：**怎么做**、**不做的后果**、**证据是什么**，并附常见误区与不适用人群。

## 怎么查

```powershell
python 数据与脚本/search.py 打鼾
python 数据与脚本/search.py 烫伤 起火      # 多个词=或
python 数据与脚本/search.py --tag L4 --list   # 只看某一层
python 数据与脚本/search.py --list           # 全部标题
python 数据与脚本/search.py 打鼾 --full      # 打印整张卡
```

### L0 · 一票否决（5 条）

整包文件：[L0-一票否决.md](L0-一票否决.md)

- [不吸烟（含电子烟）](cards/no-smoking.md) — 吸烟者全因死亡风险高 54%（≥10 支/日）、17%（<10 支/日）；少抽只是少一点，不是归零
- [不嚼槟榔](cards/no-betel.md) — 口腔黏膜下纤维化→张口困难、进食受限；口腔癌风险上升（RR 1.21）
- [交通与骑行安全](cards/road-safety.md) — 交通伤是全球青壮年第一死因；后排不系安全带同样致命；不戴盔的颅脑伤多数不可逆
- [火与气：电动车、烟雾报警器、燃气管](cards/ev-charging-gas.md) — 楼道起火 3 分钟内浓烟即可致命；一氧化碳无色无味，中毒多发生在睡着时
- [野生蘑菇与霉变粮食](cards/wild-mushroom-mold.md) — 毒蘑菇无特效解药，肝肾衰竭进展快；黄曲霉素是强致癌物，280℃ 以上才开始分解，日常加热破坏不了

### L1 · 每天（17 条）

整包文件：[L1-每天.md](L1-每天.md)

- [起床时间固定](cards/fixed-wake.md) — 作息来回漂，等于每周给自己倒一次时差：入睡变难、白天更困、情绪更差
- [睡够 7 小时左右](cards/sleep-7h.md) — 长期每晚 ≥10 小时组全因死亡高 34%（男）/48%（女）；睡不够伤免疫、代谢和情绪
- [起床后到户外见光 2–10 分钟](cards/morning-light.md) — 缺晨光，生物钟往后漂：晚上更难入睡、白天更困，情绪也更容易低
- [睡前一小时不看手机；夜里少强光](cards/no-screen-before-bed.md) — 夜间强光抑制多巴胺释放，接下来几天的情绪、专注和代谢都受影响
- [下午 2 点后不喝咖啡、浓茶](cards/caffeine-cutoff.md) — 咖啡因半衰期约 5–6 小时，下午那杯到半夜还有一半在体内，直接削掉深睡
- [主食里有一部分是全谷](cards/whole-grain.md) — 全精制主食：血糖波动大、纤维不足，全谷那部分死亡风险收益全部丢掉
- [蔬菜水果每天一斤左右](cards/veg-fruit-500g.md) — 蔬果不足是归因死亡排前列的饮食风险；缺的是纤维、钾和多酚，不是维生素片能替代的
- [每天一小把无盐坚果](cards/nuts.md) — 不吃坚果的人常用膨化零食补嘴，换来的是反式脂肪和空热量
- [不喝含糖饮料](cards/no-sugary-drinks.md) — 每天 ≥2 份含糖饮料全因死亡高 21%；纯果汁也不省事（HR 1.24）
- [加工肉基本不吃，红肉适量](cards/no-processed-meat.md) — 每天多一份加工肉全因死亡高 3%；红肉每天多半份高 10%
- [炒菜全程开抽油烟机](cards/range-hood.md) — 厨房油烟是不吸烟女性肺癌的重要暴露源；爆炒时 PM2.5 可远超室外污染日
- [不喝滚烫的热饮](cards/no-scalding-drink.md) — 65℃ 以上热饮与食管癌风险相关；反复烫伤食管黏膜是明确的机制路径
- [一天两次天然发酵食品](cards/fermented-food.md) — 菌群多样性低→免疫调节差、慢性炎症水平高；抗生素一次就能把它打散
- [走到 7000 步左右](cards/7000-steps.md) — 不动的人死亡风险显著更高；步数是最便宜、门槛最低的干预
- [不连续坐 1 小时以上](cards/break-sitting.md) — 每天久坐超过 8 小时后，每多 1 小时全因死亡风险 +4%；下班再运动也抵不掉全部
- [刷牙 + 清牙缝 + 补缺牙](cards/brush-teeth.md) — 很少刷牙者过早死亡高 25%；牙周炎与心血管、糖尿病控制相互牵连
- [白天出门见见太阳](cards/daylight.md) — 白天不见光，夜里睡不好，情绪也更容易低；长期室内生活还伴随维生素 D 不足

### L2 · 每周（6 条）

整包文件：[L2-每周.md](L2-每周.md)

- [每周 2 次力量训练](cards/strength-2x.md) — 肌肉量 30 岁后逐年下降，衰弱与跌倒是老人致死主因之一；肌肉是老年生活自理的本金
- [每周中等强度有氧 150 分钟](cards/aerobic-150.md) — 心肺适能低是最强的死亡预测指标之一；不运动者全因死亡明显更高
- [一次挥拍或球类运动](cards/racket-sport.md) — 不运动者全因死亡约为常运动者的两倍（观察性）；一个人练难坚持，球类顺便解决「孤独」
- [每周和亲人朋友真见面](cards/meet-people.md) — 社会隔离 OR 1.29、孤独 OR 1.26、独居 OR 1.32——量级和吸烟同级
- [每周自己做饭 ≥3 顿](cards/cook-at-home.md) — 外卖以超加工为主，UPF 高摄入组全因死亡 HR 1.62；油和盐也不受你控制
- [一周工作不超过 50 小时](cards/work-hours.md) — 长期超时工作推高血压、压缩睡眠、抬高抑郁风险；恢复不足会把运动和三餐一起挤掉

### L3 · 每年或按年龄（8 条）

整包文件：[L3-每年或按年龄.md](L3-每年或按年龄.md)

- [每年量血压，高了按医嘱吃药](cards/bp-yearly.md) — 高血压基本没症状，等有症状常是卒中、心衰或肾衰——那时已经不可逆
- [查空腹血糖](cards/fasting-glucose.md) — 糖尿病前期没有感觉，常以十年后的视网膜、肾脏、神经并发症现身
- [查幽门螺杆菌与丙肝抗体](cards/h-pylori-hcv.md) — 两者都是沉默的胃癌、肝硬化推手；丙肝现在能治愈，拖到肝硬化就只剩管理
- [核对乙肝接种史，需要就补种](cards/hep-b-vaccine.md) — 乙肝是肝癌主因之一，没有抗体等于没有防护；携带者不复查会错过早期肝癌
- [按年龄做癌症筛查](cards/cancer-screening.md) — 结直肠癌、宫颈癌、乳腺癌早期几乎无症状；等有症状再查，分期和预后差一个档次
- [按年龄打疫苗](cards/vaccines-age.md) — 在老人身上，一次肺炎或流感常是「最后一次住院」；带状疱疹后神经痛可持续数月到数年
- [记 BMI 和腰围](cards/bmi-waist.md) — 腰围每 +10cm 全因死亡 HR 1.11；腹型肥胖比体重更能预测代谢风险
- [打鼾憋气去做睡眠评估](cards/snoring-osa.md) — 重度睡眠呼吸暂停 HR 1.90；夜间反复缺氧持续伤心脏和大脑，还会拖累白天判断力

### L4 · 出事那一刻（8 条）

整包文件：[L4-出事那一刻.md](L4-出事那一刻.md)

- [心脏骤停：按压 + AED](cards/cpr-aed.md) — 心脏骤停每延迟 1 分钟，存活率下降 7–10%；等救护车到常常已经晚了
- [疑似卒中：直接打 120](cards/stroke-120.md) — 卒中每耽误 1 分钟约 190 万个脑细胞死亡；溶栓/取栓都有严格时间窗
- [胸口压着疼超过 15 分钟：打 120](cards/chest-pain-120.md) — 心梗拖过黄金时间，心肌坏死不可逆；坏死多少决定后半生的心功能
- [噎住：拍背 + 腹部冲击](cards/choking.md) — 完全梗阻几分钟内即脑损伤，来不及送医院
- [烫伤：凉流水冲 20 分钟](cards/burn-rinse.md) — 不冲冷水，热力继续向深层传导，浅二度变深二度；抹牙膏、酱油、香油会造成感染并干扰医生判断
- [猫狗咬伤抓破皮：当天打疫苗](cards/animal-bite.md) — 狂犬病一旦发病，病死率几乎 100%；抓破皮也算暴露，不是只有咬出血才算
- [误服：不催吐，带瓶子去医院](cards/poisoning.md) — 催吐会让腐蚀性液体二次灼伤食管；没有成分信息，医生只能盲处理
- [火灾：贴地走、先摸门、走楼梯](cards/fire-escape.md) — 浓烟 30 秒就能让人失去意识；电梯可能断电困人，是死亡高发点

### L5 · 一次性办完（8 条）

整包文件：[L5-一次性办完.md](L5-一次性办完.md)

- [换成低钠富钾盐](cards/low-sodium-salt.md) — 普通盐吃多推高血压，卒中风险随之上升；换盐是被随机试验验证过的低成本干预
- [扶手、防滑、练平衡](cards/handrail-balance.md) — 跌倒是 65 岁以上伤害死亡第一位；一次髋部骨折后一年内的功能下降常常不可逆
- [两种感冒药别叠着吃](cards/acetaminophen.md) — 叠加服用是急性肝衰竭最常见的原因之一；感冒药 + 退烧药 + 止痛药三件套最容易超量
- [感冒不吃抗生素；头孢不配酒](cards/antibiotics-alcohol.md) — 双硫仑样反应可致面红、心悸、血压骤降甚至休克；滥用抗生素毁肠道菌群并催生耐药
- [几类食物必须做熟](cards/food-safety-cook.md) — 皂苷、米酵菌酸、寄生虫都能直接进急诊；米酵菌酸没有特效解药
- [食用油备 2–3 种轮换](cards/cooking-oil.md) — 反复高温的油产生反式脂肪和氧化产物；Omega-6 超标、Omega-3 不足是现代饮食的典型失衡
- [关掉非必要通知](cards/notifications.md) — 每次被打断，要十几分钟才能回到原来的思考深度；碎片化会持续消耗精力
- [情绪持续低落超过两周就去求助](cards/mood-help.md) — 长期悲观推高全因死亡（HR 1.13），还会拖慢就医、恶化慢病管理；抑郁本身是可治疗的

### L6 · 情绪与心理（8 条）

整包文件：[L6-情绪与心理.md](L6-情绪与心理.md)

- [把能要命的东西从手边拿走（不囤安眠药、农药、百草枯）](cards/suicide-means.md) — 限制人拿到致死手段是有证据的干预：管控镇痛药后相关自杀降 43%，常有人跳楼的地点加防护后降 86%；百草枯无解药，孟加拉 257 例病死率 43.2%，救回来也可能留下不可逆的肺纤维化
- [念头一冒出来先告诉一个人，把这几十分钟交出去](cards/suicide-10min.md) — 从念头冒出来到真正动手，将近一半的人不超过 10 分钟；这个窗口短到专业人士来不及介入，能拦住的多半是身边人
- [直接问「你有没有想过自杀」，问了不会让他更想](cards/ask-suicide.md) — 不敢问，是这个念头最容易被漏掉的环节；而不问的代价，是错过那个只有十分钟的窗口
- [丧亲：头几天别一个人待着，头半年把药和三餐交给一个人](cards/grief-acute.md) — 亲人去世后 24 小时内急性心梗发作率是平时的 21.1 倍；丧偶头半年死亡风险高约四成；悲伤状态下人为了不等 3 个月愿意少拿 13%–34% 的钱——这正是被骗和做错决定的窗口
- [拿到重病诊断的第一周：别一个人去拿报告](cards/diagnosis-week.md) — 确诊癌症后第一周自杀相对风险 12.6 倍、心血管死亡 5.6 倍——最高的风险集中在「刚知道」的那几天，之后一年内迅速回落
- [哀伤卡住超过半年：去精神科或临床心理科挂号](cards/grief-stuck.md) — 大约每 10 个丧亲的成年人里有 1 个会卡住；卡住之后不是「时间没到」，而是有诊断标准、也有专门治疗的状态，靠自己熬的代价是长期的失能
- [车祸、被打、灾难之后一个月仍在噩梦闪回：做创伤聚焦治疗](cards/trauma-month.md) — 经历创伤的人平均约 8% 会发展成创伤后应激障碍；而出事后马上做的一次性心理晤谈防不住它，有一项试验里做过的人三年后反而更差
- [情绪低落时先做这五件事：动起来、多见光、按时睡、找人说、打 12356](cards/mood-first-steps.md) — 轻中度抑郁最常见的走向不是崩溃，是活动量一路掉到零：不起床、不出门、不见人，越不动越没力气动。同一批 218 项随机试验里，只做别的活动的对照组症状几乎不动，而步行或慢跑组平均好 0.62 个标准差；季节性抑郁不接受光照治疗，改善也明显更小。这五件事里唯一来不及补救的是「想不开时打个电话」。

### DONT · 省钱的别做（6 条）

整包文件：[L9-省钱的别做.md](L9-省钱的别做.md)

- [别为抗衰吃 NMN](cards/no-nmn.md) — 钱花了，健康人延寿没有任何直接证据；长期安全性未知
- [健康人别自行吃二甲双胍](cards/no-metformin-healthy.md) — 腹泻 53% vs 12%，还可能掩盖真正的病因；健康人延寿证据不成立
- [别常规吃复合维生素、大剂量维 D 求延寿](cards/no-multivitamin.md) — 随机试验为阴性（HR 0.99），等于花钱买安慰；大剂量维生素 D 还有高钙血症风险
- [别自行开始阿司匹林做一级预防](cards/no-aspirin-primary.md) — 老年试验中出血更多（HR 1.14），全因死亡没有获益，得不偿失
- [长期失眠别靠褪黑素](cards/no-melatonin.md) — 褪黑素产品规格不受控，可能引起抑郁情绪；它不解决「躺下就紧张」这类行为问题
- [别猛补钙、喝骨头汤治骨折；感冒别要求输液](cards/no-calcium-soup-iv.md) — 补钙不治骨折，过量还增加结石与心血管钙化风险；骨头汤里主要是脂肪和嘌呤；输液增加感染、过敏和静脉炎机会

## 证据分级

- `A` 随机对照或多队列强证据
- `B` 大型队列 / 系统综述，观察性关联
- `C` 弱关联或口径需修正
- `D` 无直接证据，别当结论
- `-` 常识性安全措施或实操建议，未做分级
